# Spor Salonu Otomasyonu

Bu depo şimdilik proje yer tutucusudur. Mevcut ana dalda uygulama kaynakları,
SQL şeması veya kurulum dosyası bulunmuyor. Teknoloji ve çalışma davranışı
kaynak kod görülmeden doğrulanamaz.

## Kaynakları ekleme düzeni

Uygulama kodunu `src/`, varsa veritabanı kurulum dosyalarını `sql/`,
proje belgelerini `docs/` altında tutun. README'ye gerçek teknoloji sürümleri,
veritabanı kurulumu ve çalıştırma komutlarını kaynaklarla birlikte ekleyin.
Gerçek üye verilerini, bağlantı parolalarını veya veritabanı yedeklerini yüklemeyin.

Kaynak kod bulunmadığından bu bakımda kod düzeltmesi veya çalışma testi yapılmadı.
